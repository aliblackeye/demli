# UI Sound Credits

The app's UI sound effects are **original, synthesized in-repo** — no third-party
samples, no AI-generated audio, no license obligations. They are generated by
[`scripts/gen-sounds.mjs`](../../scripts/gen-sounds.mjs) (pure Node PCM synthesis;
ffmpeg for the Ogg encode) and written to both clients:

- Desktop: `apps/desktop/src/renderer/src/sounds/assets/*.ogg` (cues + both rings)
- Mobile: `apps/mobile/assets/sounds/*.ogg` (cues, byte-identical to desktop) +
  `ring-incoming.wav` / `ring-outgoing.wav` (same audio as the desktop ring Oggs)

Regenerate with `pnpm gen:sounds`. The script is the source of truth; the
committed assets are its output, and a regenerate of unchanged audio is
byte-identical (bitexact Ogg muxing).

### Why not AI-generated audio (2026-10-20)

The sfx-refresh wave was asked to use the founder's Higgsfield account. Its only
sound-effect model, `mirelo_text_to_audio`, is labelled **"Game pipeline only"**
in Higgsfield's model catalog, and the generation tool's documentation states that
mirelo/sonilo/inworld "must not be used for standalone audio". The remaining audio
models are speech-only. So no Higgsfield output was used (0 credits spent), and
the set stayed synthesized — which also keeps the AGPL repo free of any audio
licence to audit.

## Families

The motifs (which notes, which direction) are shared, so every cue means the same
thing whichever family is active; only the timbre changes.

| id          | Name              | Character                                                                  | Level mode |
| ----------- | ----------------- | -------------------------------------------------------------------------- | ---------- |
| `porcelain` | Porselen Fincan   | Thin teacup, fingertip/teaspoon tap: warm, round, glazed. **Shipped.**      | `lufs`     |
| `teaglass`  | İnce Belli Bardak | Turkish tea glass + spoon, clear but with a softened top.                  | `lufs`     |
| `stoneware` | Sırlı Toprak      | Glazed earthenware: the darkest, shortest ceramic.                         | `lufs`     |
| `felt`      | Keçe Tahta        | Felt-beater tongue drum + breath. Shipped 2026-07-29 → 2026-10-20.          | `proxy`    |
| `marimba`   | Sıcak Marimba     | Rosewood bar, soft mallet.                                                 | `proxy`    |
| `glass`     | Yumuşak Cam       | Struck glass/bell, bright tink.                                            | `proxy`    |

`felt` still renders sample-identical to what shipped (decoded PCM md5 matched),
so going back is `ACTIVE_FAMILY = "felt"` plus a regenerate. The old `legacy` sine
family was removed.

```bash
node scripts/gen-sounds.mjs --preview --out=tmp/sfx   # candidates + index.html (old vs new)
node scripts/gen-sounds.mjs                           # write ACTIVE_FAMILY to BOTH clients
```

`ACTIVE_FAMILY` must name the family committed under the asset directories. The
script refuses a `--family=` run that would leave the two disagreeing (otherwise
the next plain run silently reverts every sound); switching means changing that
constant and regenerating in the same commit.

### How `porcelain` was picked (measured, not listened)

Nobody could listen during the wave, so the pick used gates every cue must pass
(all values from the script, cross-checked on the encoded files with
`ffmpeg -af apad=pad_dur=0.5,ebur128=peak=true`, which agreed within 0.06 LU):

- loudness within ±0.5 LU of its target, true peak ≤ −1 dBTP, mono 48 kHz;
- onset under 1 ms (a strike, not a fade-in), blip length ≤ 400 ms;
- **≤ −35 dB below peak where the tail fade starts**, i.e. the fade shapes room tail,
  it does not cut a ringing note.

Only `porcelain` passed every gate. `teaglass` failed the tail gate on
screen-start/-stop and call-connected (−30 to −33 dB); `stoneware` missed the
incoming-ring loudness (−16.8 vs −16). The founder's listening pass
(`tmp/sfx/index.html`) is the final word.

## Design language

Physical-ish **modal synthesis**:

| Layer    | What it is                                                                    |
| -------- | ----------------------------------------------------------------------------- |
| `strike` | A few ms of band-limited noise — the fingertip/spoon/mallet hitting the object. |
| `modes`  | An **inharmonic** partial stack with **per-partial decay** (highs die first).  |
| `body`   | A short low sine under the hit, so the cue has weight.                         |
| `room`   | Schroeder reverb (4 damped combs → 2 allpasses), mixed faint.                  |
| `level`  | `lufs`: BS.1770 K-weighted **max-momentary LUFS** (the standard short-SFX yardstick; integrated loudness gates a 150 ms blip to −70) + tail trim and 30 ms fade + −2 dBFS sample-peak ceiling. `proxy`: the original max-50 ms-RMS normalization. Pure gain either way — never a limiter. |

Partial ratios are the object's identity: porcelain `1 : 2.32 : 4.2 : 6.5 : 9.3`,
tea glass `1 : 2.71 : 5.2 : 8.6 : 12.9`, stoneware `1 : 2.45 : 4.6 : 7.1`. The
ceramics use short decays (fundamental τ 42–58 ms) and play the motifs at 0.8×
spacing, so a blip has physically finished inside 400 ms.

## Cues

Rising = positive, its counterpart falls; one key.

| File                 | Event                                                      | Motif                 | LUFS (shipped) |
| -------------------- | ---------------------------------------------------------- | --------------------- | -------------- |
| `ring-incoming`      | Incoming call (loop, 2.60 s)                               | C5+G5 double pair     | −16.3          |
| `ring-outgoing`      | Outgoing ringback (loop, 3.40 s)                           | A4, two taps          | −19.0          |
| `call-connected`     | A call connected                                           | C5-G5-C6 rising       | −19.0          |
| `voice-join/-leave`  | You joined / left a voice channel                          | C5↔G5 fifth           | −20.0          |
| `screen-start/-stop` | A screen share started / stopped (yours or a peer's)       | C5-E5-A5 / reverse    | −20.0          |
| `unmute`             | Mic on                                                     | C5, open              | −21.0          |
| `undeafen`           | Deafen off                                                 | F4 → C5               | −21.0          |
| `mention`            | Someone @mentioned you (direct, not @everyone)             | D5-F5-A5              | −21.0          |
| `call-ended`         | A call ended / was declined / went unanswered (caller)     | G4 → C4               | −21.0          |
| `error`              | A voice error appeared (permission, device, reconnect…)    | F4 → E4, damped       | −21.0          |
| `deafen`             | Deafen on                                                  | C5 → F4, damped       | −21.5          |
| `peer-left-call`     | The other side left the call                               | C5-A4-F4 falling      | −21.5          |
| `mute`               | Mic off                                                    | F4, damped            | −22.5          |
| `peer-join/-leave`   | Someone joined / left your voice channel                   | G4↔C5 fourth, softer  | −23.0          |
| `message`            | New message                                                | D5 → F5               | −23.5          |

`message` is deliberately the quietest: it fires most often and must never feel
like an alarm. True peak is ≤ −2.0 dBTP on every shipped file. Runtime user volume
scales from there (`sounds/sound-settings.ts`); the message switch covers `mention`.

## Wiring (same rule on both clients)

- Call outcome cues come from the **call FSM** via `callTransitionCue`
  (`packages/client-core/src/dm-calls/call-cues.ts`): the caller already sits in
  the LiveKit room while it rings, so the voice store cannot say when a call
  connected. Inside a `dmcall:` room the voice cues for self join/leave are
  silent; a remote leaving is `peer-left-call`.
- One shared gate, `createCueGate` (`packages/client-core/src/cue-gate.ts`),
  throttles bursts and drops repeats: `call-ended` right after `peer-left-call`,
  `unmute` after `undeafen`, `mute` after `deafen`, `error` after `error`.
- Desktop and mobile loop the **same** ring audio; the desktop's old Web Audio
  sine ring (C5+E5) is gone, so both platforms now ring C5+G5.
